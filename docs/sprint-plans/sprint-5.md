## Diagnostic Output Contract

- `geometry-manifest.json`: schema version, source/checkpoint identity, split/sample configuration, seeds, feature dimensions, file inventory, and checksums.
- `embeddings.npz`: numeric arrays only, including file embeddings, IDs/index linkage, labels encoded through `records.csv`, and available scalar scores.
- `records.csv`: one row per file with stable ID, split, label, anomaly family, fleet, regime summary, severity, length, and score columns; unavailable metadata is explicit rather than fabricated.
- `metrics.json`: machine-readable health, spectrum, group, neighborhood, and diagnostic-only separation metrics with sample counts and definitions.
- `neighbors.csv`: query/neighbor IDs, rank, distance/similarity, group relationships, labels, and relevant scores.
- `figures/*.png`: deterministic plots with titles, legends, sample counts, explained variance where applicable, and no hidden interactive-state dependency.

## Acceptance Criteria

- Extraction is deterministic for a fixed checkpoint, dataset manifest, configuration, and seed, and uses bounded batch memory.
- Geometry analysis consumes cached artifacts and never needs to rerun the model.
- Metrics detect constant/collapsed, anisotropic, low-rank, and healthy synthetic embeddings in focused behavioral tests.
- Labels are used only for post-hoc diagnostics, never as model inputs or projection fitting shortcuts.
- PCA/t-SNE and neighbor sampling remain bounded and deterministic under configured limits.
- Both notebooks are clean, parameterized, independently understandable, and all code cells compile without execution.
- The Kaggle gate contains matching source/notebooks, complete run instructions, provenance, and verified checksums.
- The 20260905 export is self-contained: every required notebook is present, notebook source-loading logic is compatible with the packaged `src.zip`, and neither `src.zip` nor the outer export ZIP contains `__pycache__`, `.pyc`, or `.pyo` entries.
- Every active checkpoint-consuming notebook defaults to the published Kaggle Model identity and exact checkpoint filename, resolves the attached model on Kaggle without depending on the previous dataset slug, and preserves an explicit local environment override.
- Every active notebook exposes editable source, data/cache input, checkpoint where applicable, and writable output paths in its first configuration cell; source and data/cache inputs are never selected by scanning Kaggle mounts or guessing among candidates.
- A focused CPU synthetic smoke invokes the public extraction path through final artifact inventory/manifest publication, so missing runtime helper symbols fail before the Kaggle gate.
- Agents never execute notebook cells or the real checkpoint/dataset inference and diagnostics; focused synthetic CPU smoke execution is permitted to verify runtime contracts before the explicit user-operated Kaggle gate.
